# Reprint requests

Updated September 21, 2026.

Production batches now support separate reprint requests. A request links an order SKU to the original batch and records replacement quantity, reason, and status: Requested, Approved, In production, Completed, or Cancelled.

Reprints preserve the original purchase order quantity and do not add inventory automatically. When replacement units arrive, inspect them through the normal receiving workflow. Use the request history to explain damage, color drift, short shipments, or other production defects.
